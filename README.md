✊ Rock Paper Scissors Game

A fun, interactive, and responsive Rock Paper Scissors game built using HTML, CSS, and JavaScript. Play against the computer and see who wins!

🎮 Live Demo

"Play the Game Online" (https://alirshad85939-blip.github.io/rock-paper-scissors-game/)

✨ Features

- 🎨 Modern and attractive user interface
- 📱 Responsive design for mobile, tablet, and desktop
- ✊ Three interactive choices: Rock, Paper, and Scissors
- 🤖 Random computer moves
- 🏆 Automatic winner detection
- 📊 Live player and computer score tracking
- 🔄 Reset button to restart the game
- 🎯 Instant results with win, lose, and draw messages

🛠️ Technologies Used

- HTML5 — Structures the game interface.
- CSS3 — Provides styling, colors, layout, and responsive design.
- JavaScript — Handles game logic, random choices, and score updates.

🚀 How to Run Locally

1. Clone this repository:
   
   git clone https://github.com/alirshad85939-blip/rock-paper-scissors-game.git

2. Open the project folder in VS Code.

3. Open "index.html" in your web browser.

4. Choose Rock, Paper, or Scissors and start playing!

📖 Game Rules

- Rock beats Scissors.
- Paper beats Rock.
- Scissors beats Paper.
- If both players choose the same option, the round is a draw.
